# IronPulse Gym – Android Registration and Login App

A native Android gym membership app built in Kotlin for the Mobile Web App Development module at the University of West London (2025/26).

## Features

- Register, Login and Welcome screens
- Registration form with full name, gender (RadioGroup with an "Other" option), year of birth, Member ID and password confirmation
- Validation on every field with clear error messages
- Members and the logged-in session saved with SharedPreferences, so a logged-in member goes straight to the Welcome screen

## Tech stack

Kotlin, XML layouts, SharedPreferences, Android Studio

## Run it

1. Clone the repository
2. In Android Studio, open the `ironpulse-gym-app` folder inside the repository
3. Let Gradle sync, then run it on an emulator or a physical Android device
